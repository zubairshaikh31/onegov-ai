# BHIM / UPI (NPCI) — Citizen Guide (Unofficial Explanatory)

> _Compiled from verified official information from https://www.bhimupi.org.in. Last updated 2024-01-01._

## Introduction
Unified Payments Interface enabling instant bank-to-bank mobile payments.

## Eligibility
Any Indian with a bank account and smartphone.

## Benefits
Instant, low-cost digital payments.

## Documents

- Mobile

## Process
1. Install BHIM app.
2. Link bank + UPI PIN.
3. Send/receive money.
