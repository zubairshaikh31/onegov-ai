DigiLocker (Unofficial Guide)

Based on verified official info from https://www.digilocker.gov.in.

Eligibility

Indian citizens with Aadhaar (used for sign-up).

Benefits

Instant access to issued documents (marksheets, licences), verified e-documents, paperless verification.

Documents

  • Aadhaar (for sign-up/authentication)
  • Mobile number

Process

  1. Sign up at digilocker.gov.in with Aadhaar OTP.
  2. Link mobile; set username/password.
  3. Fetch issued documents from registered issuers.
  4. Upload personal documents; share via URI/QR.

Official: https://www.digilocker.gov.in
