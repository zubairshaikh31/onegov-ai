# Maharashtra Farmer Welfare Schemes — Citizen Guide (Unofficial Explanatory)

> _Compiled from verified official information from https://mahaagri.gov.in. Last updated 2024-01-01._

## Introduction
State agriculture department schemes: farm loans, subsidies, crop insurance (PMFBY state window), and support.

## Eligibility
Maharashtra farmers with land records; scheme-specific criteria.

## Benefits
Input subsidies, loan waiver/relief, crop insurance, drip/solar subsidies.

## Documents
- 7/12 land record (Mandatory)
- Aadhaar (Mandatory)
- Bank account (Mandatory)
- Caste/category cert (if applicable) (Mandatory)

## Application Process
1. Visit mahaagri.gov.in.
2. Select scheme; apply with land/identity docs.
3. Verification; benefit disbursal.
