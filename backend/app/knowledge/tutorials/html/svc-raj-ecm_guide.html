Rajasthan e-Mitra / SSO (Unofficial Guide)

Based on verified official info from https://sso.rajasthan.gov.in.

Eligibility

Rajasthan residents; SSO ID registration.

Benefits

Unified access to hundreds of state services via e-Mitra kiosks.

Documents

  • Aadhaar
  • Mobile
  • Address proof

Process

  1. Create SSO ID on sso.rajasthan.gov.in.
  2. Use e-Mitra for services.
  3. Track and download.

Official: https://sso.rajasthan.gov.in
