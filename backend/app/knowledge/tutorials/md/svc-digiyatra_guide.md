# DigiYatra (Airport Biometric) — Citizen Guide (Unofficial Explanatory)

> _Compiled from verified official information from https://digiyatra.gov.in. Last updated 2024-01-01._

## Introduction
Biometric-based seamless airport entry using a facial recognition ecosystem.

## Eligibility
Domestic air travellers with valid ID and ticket.

## Benefits
Paperless, contactless airport check-in.

## Documents
- ID proof
- Ticket
- Aadhaar/ID for enrollment

## Process
1. Enroll on DigiYatra app.
2. Link ID + ticket.
3. Use biometric at airport.
