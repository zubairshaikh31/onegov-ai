Maharashtra Transport (RTO) Services — Citizen Guide (Unofficial Explanatory)

Based on verified official information from https://transport.maharashtra.gov.in. Verify on the official portal.

Introduction

Maharashtra State Transport Department services for DL, RC, permits via state RTOs (integrated with Parivahan).

Eligibility

Maharashtra residents / vehicle owners / licence applicants.

Benefits

State-specific DL/RC, permits, tax, and faceless services.

Documents

  • Aadhaar (Mandatory)
  • Address/age proof (Mandatory)
  • Vehicle docs (RC) (Mandatory)
  • Medical certificate (Optional)

Application Process

  1. Step 1: Use Parivahan/Sarathi or state portal.
  2. Step 2: Apply for DL/RC/permit; pay fees.
  3. Step 3: Book RTO slot; visit for test.
  4. Step 4: Receive documents (digital via DigiLocker).

Fees

As per Maharashtra MV fee schedule.

Timeline

Per RTO SLA.
