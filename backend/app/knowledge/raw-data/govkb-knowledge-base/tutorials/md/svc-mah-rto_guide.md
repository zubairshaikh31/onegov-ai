# Maharashtra Transport (RTO) Services — Citizen Guide (Unofficial Explanatory)

> _This guide is an unofficial explanatory summary based on verified official information from https://transport.maharashtra.gov.in. Always verify on the official portal._

## Introduction

Maharashtra State Transport Department services for DL, RC, permits via state RTOs (integrated with Parivahan).

## Eligibility

Maharashtra residents / vehicle owners / licence applicants.

## Benefits

State-specific DL/RC, permits, tax, and faceless services.

## Documents Required

- **Aadhaar** (Mandatory)
- **Address/age proof** (Mandatory)
- **Vehicle docs (RC)** (Mandatory)
- **Medical certificate** (Optional)

## Application Process

**Step 1:** Use Parivahan/Sarathi or state portal.
**Step 2:** Apply for DL/RC/permit; pay fees.
**Step 3:** Book RTO slot; visit for test.
**Step 4:** Receive documents (digital via DigiLocker).

## Fees

As per Maharashtra MV fee schedule.

## Timeline

Per RTO SLA.
