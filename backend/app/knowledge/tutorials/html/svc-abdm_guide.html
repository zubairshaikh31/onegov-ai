Ayushman Bharat Digital Mission (ABHA) (Unofficial Guide)

Based on verified official info from https://abdm.gov.in.

Eligibility

Any Indian resident (voluntary opt-in).

Benefits

Single health ID to link records across providers; consent-based sharing; easier continuity of care.

Documents

  • Aadhaar / Driving Licence / any govt ID for ABHA creation
  • Mobile number for OTP

Process

  1. Visit abdm.gov.in or ABHA app.
  2. Authenticate with Aadhaar OTP or other ID.
  3. Create 14-digit ABHA number / Health ID.
  4. Link PHR address and records from providers.
  5. Manage consent for record sharing.

Official: https://abdm.gov.in
