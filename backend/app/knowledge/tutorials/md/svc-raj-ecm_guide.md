# Rajasthan e-Mitra / SSO — Citizen Guide (Unofficial Explanatory)

> _Compiled from verified official information from https://sso.rajasthan.gov.in. Last updated 2024-01-01._

## Introduction
Rajasthan SSO / e-Mitra single-sign-on for state services and certificates.

## Eligibility
Rajasthan residents; SSO ID registration.

## Benefits
Unified access to hundreds of state services via e-Mitra kiosks.

## Documents
- Aadhaar (Mandatory)
- Mobile (Mandatory)
- Address proof (Mandatory)

## Application Process
1. Create SSO ID on sso.rajasthan.gov.in.
2. Use e-Mitra for services.
3. Track and download.
